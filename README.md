##  ¿Qué es TRON 3D?

**TRON 3D** es un juego de carreras futurista inspirado en la película TRON Legacy, donde pilotas **motos de luz** (Light Cycles) en una arena digital. Tu objetivo es **sobrevivir** evitando chocar con tu propio rastro, el rastro del oponente o las paredes de la arena.

### 🏍️ Importar tus Propios Modelos 3D desde Blender

#### **Paso 1: Exportar desde Blender**

```
En Blender:
1. Selecciona tu modelo 3D
2. File → Export → Wavefront (.obj)
3. O mejor: Exportar a .fbx

Configuración recomendada:
✅ Scale: 1.00
✅ Forward: -Z Forward
✅ Up: Y Up
```

#### **Paso 2: Convertir a formato .g3db**

```bash
# Instalar fbx-conv (solo primera vez)
# Descargar de: https://github.com/libgdx/fbx-conv

# Convertir tu modelo
fbx-conv -o G3DB mi_moto_personalizada.fbx mi_moto_personalizada.g3db
```

#### **Paso 3: Colocar en el proyecto**

```bash
# Copiar a la carpeta de assets
cp mi_moto_personalizada.g3db android/assets/models/
```

#### **Paso 4: Cargar en el juego**

Edita `AssetsManager.kt`:

```kotlin
object AssetsManager {
    fun loadAssets() {
        // Cargar tu modelo personalizado
        assetManager.load("models/mi_moto_personalizada.g3db", Model::class.java)
        assetManager.finishLoading()
    }
    
    fun getMiMotoPersonalizada(): Model {
        return assetManager.get("models/mi_moto_personalizada.g3db")
    }
}
```
