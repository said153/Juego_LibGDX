## 📖 Sobre este Proyecto

**TRON 3D** es un proyecto de videojuego desarrollado como demostración de programación 3D en Android usando Kotlin y LibGDX. Inspirado en la icónica película TRON Legacy, este juego recrea la experiencia de las carreras de motos de luz (Light Cycles) en una arena digital.

### 🎯 Objetivos del Proyecto
- ✅ Implementar un motor de juego 3D multiplataforma funcional
- ✅ Aplicar arquitectura MVVM en desarrollo de videojuegos
- ✅ Crear un sistema de renderizado con efectos visuales avanzados
- ✅ Desarrollar sincronización multijugador en tiempo real vía Bluetooth

### 📊 Estado Actual
🟢 **Versión Beta Funcional** - Todas las características principales implementadas y probadas

##  ¿Qué es TRON 3D?

**TRON 3D** es un juego de carreras futurista donde pilotas **motos de luz** (Light Cycles) en una arena digital. Tu objetivo es **sobrevivir** evitando chocar con tu propio rastro, el rastro del oponente o las paredes de la arena.

### 🐛 Problemas Comunes y Soluciones

#### ❌ **Error: "Redeclaration: class AndroidLauncher"**

**Síntoma:**
```
e: Redeclaration: class AndroidLauncher
BUILD FAILED
```

**Solución:**
```bash
# 1. Revisar android/src/main/kotlin/.../AndroidLauncher.kt
# 2. Verificar que solo exista UNA declaración de clase
# 3. Eliminar archivos temporales .kt~

# 4. Limpiar y reconstruir
./gradlew clean
./gradlew build
```

---

#### ❌ **Modelos 3D no se cargan**

**Síntoma:** Pantalla negra, motos no aparecen

**Solución:**
```bash
# Verificar ubicación de modelos
ls android/assets/models/
# Debe mostrar: moto_azul.g3db, moto_naranja.g3db, arena.g3db

# Verificar nombres en código coincidan exactamente
```

---

#### ❌ **Bajo rendimiento / FPS bajos**

**Solución:**
```kotlin
// Editar: core/src/.../config/TronVisualConfig.kt
const val ENABLE_BLOOM = false  // Desactivar en gama baja
const val TRAIL_SEGMENTS_MAX = 100  // Reducir de 500
```

---

#### ❌ **Bluetooth no conecta**

**Verificar:**
- ✅ Permisos en AndroidManifest.xml
- ✅ Bluetooth activado en ambos dispositivos
- ✅ Dispositivos emparejados previamente
- ✅ Android 12+ requiere permisos BLUETOOTH_CONNECT

## 🏍️ Importar Modelos 3D desde Blender

### ¿Por qué convertir a .g3db?

LibGDX no renderiza directamente `.obj` o `.fbx`. El formato `.g3db` es optimizado para LibGDX: menor tamaño, carga rápida, compatible con el motor.

### Paso 1: Exportar desde Blender

```
Blender:
1. File → Export → FBX (.fbx)

Configuración:
✅ Scale: 1.00
✅ Forward: -Z Forward
✅ Up: Y Up
✅ Apply Modifiers: ☑
```

### Paso 2: Convertir a .g3db

```bash
# Descargar fbx-conv
# https://github.com/libgdx/fbx-conv

# Convertir
fbx-conv -o G3DB mi_moto.fbx mi_moto.g3db
```

### Paso 3: Colocar en proyecto

```bash
cp mi_moto.g3db android/assets/models/
```

### Paso 4: Cargar en el juego

```kotlin
// AssetsManager.kt
assetManager.load("models/mi_moto.g3db", Model::class.java)
```
